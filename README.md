# JualinPro AI

AI Sales Assistant untuk membantu UMKM dan seller Indonesia meningkatkan penjualan.

## Fitur

- AI Deskripsi Produk
- AI Caption Sosial Media
- AI Script Video Jualan
- AI Balas Chat Pelanggan
- Riwayat konten AI
- Dashboard penjualan
- Paket Gratis dan Pro

## Teknologi

- Expo / React Native
- Supabase
- AI API
- EAS Build

## Status

Versi awal dalam tahap pengembangan.

## Tujuan

Membantu seller membuat konten jualan dengan lebih cepat, mudah, dan profesional.
